# G2 test design re-review

Decision: changes requested.

- review_tests:1:1 resolved. Collector-output corruption now checks every singleton and evidence binding, and real Go environment changes exercise build tags and platform context. These provide useful independent-validation coverage.
- review_tests:1:2 open. The new predecessor, copied-checkout receipt, symlink-root, cancellation and publication tests are valuable, but none establishes an actual receipt under one profile or inventory and attempts reuse under an incompatible profile or inventory. Corrupt predecessor contents and a store path replaced between validation and use are also absent. A check only against a symlink already present before a plan cannot catch the specified replacement race. Add focused tests asserting incompatible/corrupted chains cannot narrow and replacement cannot redirect reads or writes; use deterministic fault injection if necessary.
- review_tests:1:3 open. The sole real production subprocess uses --plan, and the executed fallback uses a private synthetic profile. Consequently a production command that cannot execute, recurses on fallback, emits child logs into JSON stdout, or omits actual preparation/gates can pass. Add a production-entry execution integration with an actual full fallback (and focused observation of its workflow, nonrecursion, output and failure propagation). Keep the normal stable-input assumption; no concurrent-change proof is required.
- review_tests:1:4 resolved. The added inverse, new-test discovery, removed source, rebinding, unverified boundary, mixed-language and resource cases address the main missing mapping cases.

The reported 8.7-second run is an incomplete red measurement at checkpoint f63b4c29, before the rebased checkpoint under review: 22 tests stop at the absent implementation seam. It does not establish completed test behavior or completed cost. Re-measure after implementation; the existing fixture cost is justified by the real languages and runners.
